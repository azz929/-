# نظام إدارة وتنظيم المكاتبات

## &#11088; النسخة الأسهل: تطبيق الويب (موصى بها)

في مجلد `app` ملف واحد اسمه **`المكاتبات.html`** — نزّله وافتحه بنقرة مزدوجة في أي متصفح (كروم/إيدج) **بدون أي تثبيت**:

- إضافة وتعديل وحذف وبحث فوري وتصفية وفرز وتنقل بين السجلات
- لوحة تحكم بإحصائيات حية وإحصائية شهرية
- إدارة الجهات والتصنيفات
- طباعة تقارير وتصدير Excel
- نسخ احتياطي واستعادة بضغطة زر + سجل حركة لكل العمليات
- البيانات تُحفظ تلقائياً في جهازك (قاعدة بيانات المتصفح) وتتسع لمئات آلاف السجلات
- عربي كامل من اليمين لليسار وبدون أي مشاكل ترميز

> ملاحظة: البيانات مرتبطة بالمتصفح على جهازك، فاحرص على أخذ نسخة احتياطية دورياً من تبويب «النسخ الاحتياطي» (سيذكرك التطبيق تلقائياً).

# نسخة Microsoft Access (بديلة)

برنامج متكامل لتنظيم وتحرير المكاتبات (الوارد والصادر) مبني على Microsoft Access، مع واجهة مستخدم عربية (من اليمين إلى اليسار) وأزرار تنقل وحفظ وبحث وتصفية وفرز، وتقارير طباعة واستعلامات جاهزة.

الفكرة: بدلاً من ملف قاعدة بيانات جاهز، يحتوي المشروع على **وحدات VBA تبني البرنامج كاملاً تلقائياً** (الجداول، العلاقات، الاستعلامات، النماذج، التقرير) بأمر واحد. هذا يجعل البرنامج قابلاً للمراجعة والتخصيص وإعادة البناء في أي وقت.

---

## المميزات

- **إضافة وتعديل وحذف** المكاتبات من نموذج واحد واضح مع رسائل تأكيد.
- **أزرار تنقل منطقية**: الأول / السابق / التالي / الأخير + عداد يعرض «سجل س من ص».
- **حفظ وتراجع**: زر حفظ يتحقق من وجود تغييرات، وزر تراجع يلغي التعديلات غير المحفوظة.
- **بحث فوري** في رقم المكاتبة والموضوع والملاحظات واسم الجهة والتصنيف.
- **تصفية** حسب النوع (وارد/صادر) والتصنيف والحالة، مع زر «عرض الكل».
- **فرز** بالتاريخ أو بالرقم، ويتبدل الاتجاه (تصاعدي/تنازلي) عند كل ضغطة.
- **واجهة رئيسية (لوحة تحكم)** بإحصائيات حية: إجمالي المكاتبات، الوارد، الصادر، المتأخرة.
- **استعلامات جاهزة**: الوارد، الصادر، المتأخرة، بحث معلمي، إحصائية شهرية، حسب التصنيف.
- **تقرير طباعة** جدولي بالعربية مع ترقيم صفحات وإجمالي عدد المكاتبات.
- **إرفاق ملف** لكل مكاتبة (مسار ملف ممسوح ضوئياً مثلاً) مع زر لفتحه مباشرة.
- **معايير حديثة**: جداول مُطبَّعة (Normalization)، تكامل مرجعي بمفاتيح أجنبية، فهارس لتسريع البحث، استعلام معلمي آمن، واجهة RTL كاملة، ونموذج بدء تشغيل تلقائي.

---

## المتطلبات

- Microsoft Access 2010 أو أحدث (يُفضَّل 2016 / 365).
- نظام Windows بأي لغة — النصوص العربية في الأكواد محمية بترميز يونيكود آمن يعمل على أي جهاز بدون أي إعدادات إضافية.

## التركيب السريع (الطريقة الموصى بها - أمر واحد)

1. نزّل هذا المستودع كملف ZIP وفك الضغط على جهاز Windows مثبّت عليه Microsoft Access.
2. افتح PowerShell داخل مجلد المشروع وشغّل:

<div dir="ltr">

```
powershell -ExecutionPolicy Bypass -File Build-Accdb.ps1
```

</div>

3. انتظر ثوانٍ وسيظهر ملف **`المكاتبات.accdb`** جاهزاً بالكامل في نفس المجلد — افتحه بنقرة مزدوجة وستظهر الواجهة الرئيسية تلقائياً.

السكربت يقوم بكل شيء نيابة عنك: يحوّل الترميز، ينشئ قاعدة البيانات، يستورد الأكواد، ويبني الجداول والنماذج والاستعلامات والتقرير.

---

## التركيب اليدوي (طريقة بديلة)

1. **حمِّل المشروع**: نزّل هذا المستودع كملف ZIP وفك الضغط.
2. **جهّز ملفات الوحدات**: شغّل من داخل مجلد المشروع:

<div dir="ltr">

```
powershell -ExecutionPolicy Bypass -File tools\Convert-Modules.ps1
```

</div>

   سيُنشأ مجلد `dist` يحوي نسخاً من الوحدات بترميز آمن (تتحول النصوص العربية إلى رموز يونيكود تُفك تلقائياً وقت التشغيل، فتعمل على أي جهاز مهما كانت لغة النظام).
3. **أنشئ قاعدة بيانات فارغة**: افتح Access ثم «قاعدة بيانات فارغة» وسمِّها مثلاً `المكاتبات.accdb`.
4. **فعّل المحتوى**: إذا ظهر شريط تحذير الأمان الأصفر اضغط «تمكين المحتوى».
5. **استورد الوحدات**: اضغط <kbd>Alt</kbd>+<kbd>F11</kbd> لفتح محرر VBA، ثم من قائمة File → Import File استورد الملفات الستة من مجلد `dist`:
   - `basMain.bas`
   - `basBuildTables.bas`
   - `basBuildQueries.bas`
   - `basBuildForms.bas`
   - `basBuildReport.bas`
   - `basHandlers.bas`
6. **ابنِ البرنامج**: في محرر VBA اضغط <kbd>Ctrl</kbd>+<kbd>G</kbd> لفتح النافذة الفورية (Immediate) واكتب:

<div dir="ltr">

```
BuildAll
```

</div>

   ثم اضغط <kbd>Enter</kbd>. خلال ثوانٍ سيتم بناء الجداول والاستعلامات والنماذج والتقرير مع بيانات تجريبية، وستُفتح الواجهة الرئيسية تلقائياً.
7. **احفظ الملف**. من الآن فصاعداً ستُفتح الواجهة الرئيسية تلقائياً عند فتح الملف.

> ملاحظة: إعادة تشغيل `BuildAll` تعيد بناء كل شيء من الصفر (تُحذف البيانات المدخلة). استخدمها فقط عند أول تركيب أو عندما تريد البدء من جديد.

## استخدام البرنامج

### الواجهة الرئيسية `frmMain`
لوحة تحكم تعرض إحصائيات حية (الإجمالي / الوارد / الصادر / المتأخرة) وأزراراً لكل الوظائف: تسجيل مكاتبة جديدة، سجل المكاتبات، الوارد، الصادر، المتأخرة، بحث سريع، الجهات، التصنيفات، التقرير، الإحصائية الشهرية، والخروج.

### نموذج المكاتبات `frmCorrespondence`
- **شريط البحث** أعلى النموذج: اكتب أي كلمة واضغط «بحث» (أو Enter) للتصفية الفورية.
- **شريط التصفية**: اختر النوع أو التصنيف أو الحالة وسيُطبَّق الفلتر مباشرة. «عرض الكل» يلغي كل الفلاتر.
- **أزرار الفرز**: «فرز بالتاريخ» و«فرز بالرقم» — كل ضغطة تعكس الاتجاه.
- **أزرار التنقل** أسفل النموذج مع عداد السجلات.
- **الإجراءات**: جديد / حفظ / حذف (مع تأكيد) / تراجع / تقرير / إغلاق.
- **الملف المرفق**: زر «..» لاختيار ملف من الجهاز، وزر «فتح» لفتحه.

### الاستعلامات الجاهزة

| الاستعلام | الوظيفة |
|---|---|
| `qryAllCorrespondence` | سجل شامل بجميع المكاتبات بأسماء أعمدة عربية |
| `qryIncoming` / `qryOutgoing` | الوارد / الصادر |
| `qryOverdue` | المكاتبات التي تجاوزت تاريخ الاستحقاق ولم تُنجز |
| `qrySearchParam` | استعلام معلمي: يسألك عن كلمة البحث عند تشغيله |
| `qryMonthlyStats` | عدد الوارد والصادر لكل شهر |
| `qryByCategory` | عدد المكاتبات حسب التصنيف |

## بنية قاعدة البيانات

- **tblCorrespondence** (المكاتبات): رقم المكاتبة، التاريخ، النوع (وارد/صادر)، التصنيف، الجهة، الموضوع، الأولوية، الحالة، تاريخ الاستحقاق، رقم الإشارة/الرد، الملف المرفق، ملاحظات، تاريخ الإدخال.
- **tblCategories** (التصنيفات) و **tblEntities** (الجهات): جداول مرجعية مرتبطة بالجدول الرئيسي بمفاتيح أجنبية لضمان التكامل المرجعي.
- فهارس على التاريخ ورقم المكاتبة والموضوع والحالة لتسريع البحث والفرز.

## أسئلة شائعة

**النصوص العربية ظهرت رموزاً غريبة (؟؟؟ أو رموز لاتينية مشوهة)؟**
هذا يحدث إذا استوردت الملفات من مجلد `src` مباشرة، أو استخدمت نسخة قديمة من المشروع. الحل: احذف ملف `.accdb` المعطوب، نزّل أحدث نسخة من المشروع، وشغّل `Build-Accdb.ps1` من جديد — النسخة الحالية تحوّل كل النصوص العربية إلى ترميز يونيكود آمن يعمل على أي جهاز مهما كانت لغة النظام.

**زر لا يعمل وتظهر رسالة أمان؟**
اضغط «تمكين المحتوى» في شريط التحذير، أو أضف مجلد الملف إلى «المواقع الموثوقة» من: ملف ← خيارات ← مركز التوثيق.

**كيف أضيف تصنيفاً أو جهة جديدة؟**
من الواجهة الرئيسية: زر «التصنيفات» أو «الجهات»، وأضف السطر الجديد مباشرة في ورقة البيانات.

**كيف أعدل تصميم نموذج؟**
كأي نموذج Access: كليك يمين على النموذج ← «عرض التصميم». أو عدّل القيم في `basBuildForms.bas` وأعد تشغيل `BuildAll` (تنبيه: يعيد البناء من الصفر).

**نصائح للاستخدام المؤسسي**
- فعّل «ضغط وإصلاح عند الإغلاق» من خيارات Access.
- عند مشاركة البرنامج على الشبكة، قسّم القاعدة (أدوات قاعدة البيانات ← تقسيم قاعدة البيانات) بحيث تبقى الجداول في ملف خلفي مشترك والنماذج في ملف أمامي لكل مستخدم.
- خذ نسخة احتياطية دورية من الملف.
